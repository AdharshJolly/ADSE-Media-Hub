# Collaboration Features Implementation Plan

## Overview
Add task comments, activity feed, and resource links to the ADSE Hub, enabling team members to collaborate directly on tasks without leaving the platform.

---

## Feature 1: Task Comments

**Purpose**: Team members and coordinators can discuss tasks inline, leave feedback, and ask questions.

### Database Schema
```sql
CREATE TABLE IF NOT EXISTS task_comments (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  task_id uuid REFERENCES tasks(id) ON DELETE CASCADE,
  user_id uuid REFERENCES users(id) ON DELETE CASCADE,
  content text NOT NULL,
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now()
);

CREATE INDEX idx_task_comments_task_id ON task_comments(task_id);
CREATE INDEX idx_task_comments_created_at ON task_comments(created_at);
```

### Types (`src/types/database.ts`)
```typescript
export interface TaskComment {
  id: string;
  task_id: string;
  user_id: string;
  content: string;
  created_at: string;
  updated_at: string;
  user?: User;
}
```

### DB Functions (`src/lib/db.ts`)
- `getTaskComments(taskId)` — fetch comments with user info, ordered by created_at
- `createTaskComment(taskId, userId, content)` — insert comment, return with user info
- `updateTaskComment(commentId, content)` — update own comment
- `deleteTaskComment(commentId)` — delete own comment (or coordinator can delete any)

### API Endpoints
| Method | Route | Description |
|--------|-------|-------------|
| GET | `/api/tasks/[id]/comments` | List comments for a task |
| POST | `/api/tasks/[id]/comments` | Create a comment |
| PATCH | `/api/comments/[id]` | Update a comment |
| DELETE | `/api/comments/[id]` | Delete a comment |

### UI (`src/components/Tasks/TaskComments.tsx`)
- Comment list with user avatar, name, timestamp
- Comment input textarea with "Post" button
- Edit/delete own comments inline
- Auto-refresh after posting

## Feature 2: Activity Feed

**Purpose**: Automatically log all task state changes so the team has a chronological history.

### Database Schema
```sql
CREATE TABLE IF NOT EXISTS task_activity (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  task_id uuid REFERENCES tasks(id) ON DELETE CASCADE,
  user_id uuid REFERENCES users(id) ON DELETE SET NULL,
  action text NOT NULL,
  details jsonb,
  created_at timestamptz DEFAULT now()
);

CREATE INDEX idx_task_activity_task_id ON task_activity(task_id);
CREATE INDEX idx_task_activity_created_at ON task_activity(created_at);
```

### Types (`src/types/database.ts`)
```typescript
export interface TaskActivity {
  id: string;
  task_id: string;
  user_id: string | null;
  action: string;
  details: Record<string, unknown> | null;
  created_at: string;
  user?: User;
}
```

### DB Functions (`src/lib/db.ts`)
- `logTaskActivity(taskId, userId, action, details?)` — insert activity record
- `getTaskActivity(taskId)` — fetch activity with user info, ordered by created_at desc

### API Endpoints
| Method | Route | Description |
|--------|-------|-------------|
| GET | `/api/tasks/[id]/activity` | List activity for a task |

### UI (`src/components/Tasks/TaskActivity.tsx`)
- Timeline-style list in task detail sidebar
- Icon + user name + action description + relative timestamp
- Auto-refresh after status/assignment changes

### Integration Points
Call `logTaskActivity` in existing handlers:
- `POST /api/tasks` → log `created`
- `PATCH /api/tasks/[id]/status` → log `status_changed` with `{ from, to }`
- `PATCH /api/tasks/[id]/assign` → log `assigned` with `{ assignee_name }`
- `POST /api/tasks/[id]/comments` → log `commented`
- `POST /api/tasks/[id]/links` → log `link_added`

## Feature 3: Resource Links

**Purpose**: Add Google Drive links, Figma links, or any external URLs to tasks for easy reference.

### Database Schema
```sql
CREATE TABLE IF NOT EXISTS task_links (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  task_id uuid REFERENCES tasks(id) ON DELETE CASCADE,
  user_id uuid REFERENCES users(id) ON DELETE SET NULL,
  url text NOT NULL,
  title text NOT NULL DEFAULT '',
  description text NOT NULL DEFAULT '',
  created_at timestamptz DEFAULT now()
);

CREATE INDEX idx_task_links_task_id ON task_links(task_id);
```

### Types (`src/types/database.ts`)
```typescript
export interface TaskLink {
  id: string;
  task_id: string;
  user_id: string | null;
  url: string;
  title: string;
  description: string;
  created_at: string;
  user?: User;
}
```

### DB Functions (`src/lib/db.ts`)
- `getTaskLinks(taskId)` — list links with user info
- `createTaskLink(taskId, userId, url, title, description)` — insert link
- `deleteTaskLink(linkId)` — delete own link (or coordinator can delete any)

### API Endpoints
| Method | Route | Description |
|--------|-------|-------------|
| GET | `/api/tasks/[id]/links` | List links for a task |
| POST | `/api/tasks/[id]/links` | Add a link |
| DELETE | `/api/links/[id]` | Delete a link |

### UI (`src/components/Tasks/TaskLinks.tsx`)
- Link list with icon (auto-detected from domain: Google Drive, Figma, etc.), title, URL, added by, date
- "Add Link" form with URL input, optional title, optional description
- Click to open in new tab
- Delete button (own links or coordinator)
